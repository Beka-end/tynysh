# Письма для входа

Два готовых шаблона. Вставляются в Supabase → **Authentication** → **Emails** →
вкладка **Templates**.

| Файл | Куда вставить | Тема письма |
|---|---|---|
| `magic-link.html` | шаблон **Magic Link** — приходит тем, кто уже регистрировался | `Код для входа в Tynysh` |
| `confirm-signup.html` | шаблон **Confirm signup** — приходит новичку при регистрации | `Подтверди почту — Tynysh` |

Оба обязательны: Supabase выбирает шаблон сам, в зависимости от того, новый
человек или уже был.

## Зачем это нужно

Главное в этих письмах — строка `{{ .Token }}`: шесть цифр, которые человек
вводит на сайте руками. Пока кода в письме нет, вход держится только на ссылке,
а ссылка ломается тремя способами:

- почтовый робот Mail.ru или Outlook открывает её раньше человека и «съедает»;
- письмо открыли на другом устройстве, а вход начали на телефоне;
- пришло новое письмо, а человек жмёт на старое.

С кодом ни один из этих случаев не мешает.

## Как вставить

1. Открой нужный шаблон в Supabase.
2. Впиши тему письма из таблицы выше.
3. Сотри то, что там лежит по умолчанию, и вставь содержимое файла целиком.
4. **Save**.

Фигурные скобки `{{ .Token }}` и `{{ .ConfirmationURL }}` трогать нельзя —
Supabase подставляет в них настоящие значения.

## Проверка

Попроси знакомого зайти с чужого адреса. В письме должны быть видны крупные
шесть цифр, и они должны подойти на странице входа.
