# Tynysh — план запуска для первых клиентов

Мессенджер (чаты, группы, поиск по @юзернейму) + встроенный AI-помощник «Дос».
Чаты бесплатно навсегда. Деньги — подписка «Дос Plus».

## Из чего состоит продукт (простыми словами)

| Часть | Что это | Чем делаем |
|---|---|---|
| Сайт/приложение | то, что видит человек в браузере и на телефоне | Next.js (React) — тот же язык, что в прототипе |
| База данных | где лежат аккаунты, чаты, сообщения | Supabase (Postgres) |
| Вход | код на почту (SMS — позже) | Supabase Auth + свой SMTP |
| «Живые» сообщения | чтобы сообщение прилетало сразу, без обновления страницы | Supabase Realtime |
| Дос | ответы AI | Claude API, вызывается ТОЛЬКО с сервера (ключ никогда не в браузере) |
| Оплата | Дос Plus | Сначала Kaspi-ссылка + ручная активация (как ты уже делаешь). Автосписание — позже |
| Хостинг | где всё крутится | Vercel (как KÁSIP) |

## Порядок работы — 6 этапов, ~5 часов в неделю

### Этап 1. Каркас (неделя 1)
- Завести проект в Supabase, выполнить `supabase/schema.sql`.
- Создать Next.js-проект, подключить Supabase.
- Вход по почте работает (код из письма). Телефон — позже, вместе с SMS-провайдером.
Готово, когда: ты вошёл и видишь пустой список чатов.

### Этап 2. Чаты (неделя 2)
- Поиск по @юзернейму, личные чаты, группы.
- Сообщения приходят в реальном времени, галочки прочитано.
Готово, когда: ты с телефона и с ноутбука переписываешься сам с собой в реальном времени.

### Этап 3. Дос (неделя 3)
- Серверный маршрут `/api/dos`: берёт историю, ходит в Claude, отвечает.
- Пакет на знакомство: 20 сообщений всего (цифра в таблице `app_settings`), счётчик в базе.
- Кризисные слова → карточка с 150 / 111 / 112 (и на клиенте, и в промпте).
Готово, когда: Дос отвечает, а на 21-м сообщении показывается окно Plus.

### Этап 4. Оплата и безопасность (неделя 4)
- Кнопка «Оплатить через Kaspi» → ссылка Kaspi + экран «пришли скрин, активируем за 10 минут».
- Админ-страница (только для тебя): включить Plus пользователю, посмотреть жалобы.
- Жалоба / блокировка пользователя работают.
Готово, когда: ты сам купил Plus как пользователь и активировал себе через админку.

### Этап 5. Документы и магазины (неделя 5)
- Разместить `docs/privacy-policy.md` и `docs/terms.md` на сайте (после проверки юристом).
- Домен, иконка, экран-заглушка «установить на телефон» (PWA — работает без App Store).
- Прогнать `docs/launch-checklist.md`.

### Этап 6. Первые 30 человек (неделя 6)
- Не «запуск на всех», а одна компания/класс: 20–30 человек, которые знают друг друга.
- Каждый день смотреть: сколько написали Досу, где отвалились, что сломалось.
- Через 2 недели — первые 5 продаж Plus руками (лично написать самым активным).
- Дос — помощник, а не психолог: так и называем его везде, включая разговоры с людьми.

## Как работать с локальным Клодом
1. Скопируй эту папку в папку проекта.
2. Открой локального Клода в этой папке — он сам прочитает `CLAUDE.md`.
3. Давай ему по одному этапу: «Сделай этап 1 из README».
4. После каждого этапа — проверяй «Готово, когда…» своими руками, не верь на слово.
