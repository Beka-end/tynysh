# Инструкции для Claude Code — проект Tynysh

Ты собираешь Tynysh — приложение, в котором подросток говорит с Досом,
AI-помощником для поддержки. Чаты между людьми написаны, но выключены
выключателем `CHATS_ENABLED` в `src/lib/features.ts`: продукт — Дос, а
переписка между подростками тянет за собой модерацию травли и взрослых
под видом сверстников, которую владелец вести в одиночку не может. Владелец проекта — не программист, объясняй действия простыми словами и по одному шагу. Перед каждым этапом кратко скажи, что будешь делать, после — как проверить руками.

## Стек (не менять без обсуждения)
- Next.js 15 (App Router) + TypeScript + Tailwind. Язык интерфейса: русский.
- Supabase: Auth, Postgres, Realtime, Row Level Security.
- Вход — код из письма, с включённым подтверждением почты. Пароль сознательно
  выключен: без подтверждения он позволял занять чужой адрес и запирал тех,
  кто забыл пароль. Вход по номеру выключен до подключения SMS. Выключатели —
  в `src/lib/login-config.ts`, служебный доступ к телефону — `/login?phone=1`.
- Claude API (`claude-sonnet-4-6`) — только в серверных route handlers. Ключ в `ANTHROPIC_API_KEY`, никогда не в клиентском коде и не в `NEXT_PUBLIC_*`.
- Хостинг Vercel. Секреты только в `.env.local` (в `.gitignore`) и в настройках Vercel.

## Схема базы
См. `supabase/schema.sql`. Не изменяй таблицы без обновления этого файла.

## Дизайн
Белый и спокойный синий. Шрифт Nunito, мобильный экран — приоритет.
Цвета живут в `src/app/globals.css`, в коде только токены (`text-tynysh`,
`bg-tynysh-soft`), никаких шестнадцатеричных значений по месту.

- основной синий #2E6FA8 — кнопки и свои сообщения
- фон #F2F7FB, мягкая плашка #E3EDF6, рамки #DCE8F2
- пузырь Доса — белый с тонкой рамкой
- единственное тёплое пятно — карточка SOS #FFE8E4

Смысл палитры: приложение открывают, когда тяжело. Экран должен давать
выдохнуть, а не бодрить, поэтому ярких пятен нет. Любая новая пара цветов
проверяется на контраст — тексту нужно 4.5:1, иначе на солнце не прочесть.

Иконки на телефон рисует `scripts/make-icons.py` — меняешь цвет, перезапусти
его, иначе на телефоне останется иконка старого цвета.

Прототип `prototype/tynysh-messenger.jsx` остаётся как источник вёрстки
и формы экранов, но не цветов: он фиолетовый.

## Дос (AI-помощник) — правила безопасности, обязательны
- Системный промпт лежит в `src/lib/dos-prompt.ts` — скопируй из прототипа, не сокращай раздел «Безопасность».
- Кризисные слова проверяются на сервере в `/api/dos` ДО вызова модели. При срабатывании ответ модели всё равно идёт, но в ответе API ставится флаг `crisis: true`, клиент показывает карточку 150 / 111 / 112.
- Дос не ставит диагнозы, не назначает лекарства, не обсуждает способы вреда, не даёт диет.
- Лимит: бесплатному даётся пакет на знакомство — по умолчанию 10 сообщений ВСЕГО (не в сутки). Цифра лежит в таблице `app_settings` (`dos_free_total`), расход — в `dos_usage`, выдача — функция `dos_take_slot()`. Plus — потолок честного использования `dos_plus_daily` в `app_settings` (по умолчанию 5 в день; 0 — без потолка). Проверка на сервере, не на клиенте. Кризисный ответ выдаётся даже когда пакет кончился.
- История с Досом хранится в `dos_messages` только для самого пользователя (RLS). Пользователь может удалить всю историю одной кнопкой.

## Что нельзя
- Не логировать тексты сообщений на сервере.
- Не показывать номер телефона другим пользователям — только @юзернейм.
- Не пускать младше 13 лет (поле `birth_year` в профиле).
- Не ставить рекламу.
