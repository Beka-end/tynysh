# Инструкции для Claude Code — проект Tynysh

Ты собираешь мессенджер Tynysh. Владелец проекта — не программист, объясняй действия простыми словами и по одному шагу. Перед каждым этапом кратко скажи, что будешь делать, после — как проверить руками.

## Стек (не менять без обсуждения)
- Next.js 15 (App Router) + TypeScript + Tailwind. Язык интерфейса: русский.
- Supabase: Auth (phone OTP), Postgres, Realtime, Row Level Security.
- Claude API (`claude-sonnet-4-6`) — только в серверных route handlers. Ключ в `ANTHROPIC_API_KEY`, никогда не в клиентском коде и не в `NEXT_PUBLIC_*`.
- Хостинг Vercel. Секреты только в `.env.local` (в `.gitignore`) и в настройках Vercel.

## Схема базы
См. `supabase/schema.sql`. Не изменяй таблицы без обновления этого файла.

## Дизайн
Возьми за основу `prototype/tynysh-messenger.jsx`: шрифт Nunito, фиолетовый #5B4BDB, фон #F6F3FF, пузыри Доса #FFF3DC. Мобильный экран — приоритет.

## Дос (AI-помощник) — правила безопасности, обязательны
- Системный промпт лежит в `src/lib/dos-prompt.ts` — скопируй из прототипа, не сокращай раздел «Безопасность».
- Кризисные слова проверяются на сервере в `/api/dos` ДО вызова модели. При срабатывании ответ модели всё равно идёт, но в ответе API ставится флаг `crisis: true`, клиент показывает карточку 150 / 111 / 112.
- Дос не ставит диагнозы, не назначает лекарства, не обсуждает способы вреда, не даёт диет.
- Лимит: бесплатному даётся пакет на знакомство — по умолчанию 20 сообщений ВСЕГО (не в сутки). Цифра лежит в таблице `app_settings` (`dos_free_total`), расход — в `dos_usage`, выдача — функция `dos_take_slot()`. Plus — без лимита. Проверка на сервере, не на клиенте. Кризисный ответ выдаётся даже когда пакет кончился.
- История с Досом хранится в `dos_messages` только для самого пользователя (RLS). Пользователь может удалить всю историю одной кнопкой.

## Что нельзя
- Не логировать тексты сообщений на сервере.
- Не показывать номер телефона другим пользователям — только @юзернейм.
- Не пускать младше 13 лет (поле `birth_year` в профиле).
- Не ставить рекламу.
