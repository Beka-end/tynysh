# Чек-лист перед первыми клиентами

## Техника
- [ ] Ключ Claude API лежит только на сервере (проверить: в исходниках сайта в браузере его нет)
- [ ] Вход по SMS работает на реальном номере KZ
- [ ] Удалены **все** тестовые номера из Supabase → Authentication → Phone → Test OTP (пока они есть, любой, кто знает пару «номер + код», войдёт в этот аккаунт)
- [ ] Заглушки Twilio заменены на настоящие ключи SMS-провайдера
- [ ] Сообщение с телефона приходит на ноутбук за < 2 сек
- [ ] На 16-м сообщении Досу показывается окно Plus (у бесплатного)
- [ ] Кризисная фраза → карточка 150/111/112 появляется
- [ ] Жалоба на пользователя попадает в админку, блокировка скрывает его сообщения
- [ ] Кнопка «Удалить историю с Досом» реально удаляет из базы
- [ ] Удаление аккаунта работает
- [ ] Сайт открывается как приложение на телефоне (PWA: иконка на экране, полноэкранно)
- [ ] Резервные копии базы включены в Supabase

## Документы и деньги
- [ ] Политика конфиденциальности и соглашение проверены юристом и лежат по ссылкам /privacy и /terms
- [ ] Галочка «Мне 13+ / согласие родителя» при регистрации
- [ ] Kaspi-ссылки на 990 ₸ и 7 900 ₸ созданы, в окне оплаты написано «пришли скрин в @tynysh_support — активируем за 10 минут»
- [ ] Ты можешь включить Plus пользователю из админки за 30 секунд
- [ ] Посчитана себестоимость: сколько стоит один разговор с Досом (смотреть расход в консоли Anthropic после 100 разговоров)

## Люди
- [ ] Выбрана первая группа 20–30 человек, которые знают друг друга
- [ ] Есть чат поддержки (Telegram/WhatsApp) — куда писать, если сломалось
- [ ] Ты сам ответишь любому за < 1 часа первые 2 недели
- [ ] Заготовлены 3 коротких видео для TikTok/Reels про Доса (диалоги без личных данных)
- [ ] Договорённость хотя бы с одним психологом/клиникой: куда Дос предлагает записаться, и на каких условиях

## Что смотреть каждый день первые 2 недели
- сколько человек зашло и сколько вернулось на следующий день
- сколько написали Досу хотя бы 1 сообщение
- сколько упёрлись в лимит 15 (это будущие покупатели)
- сколько жалоб и сколько кризисных карточек
