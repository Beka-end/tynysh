## Блок 1. Чтобы чужой человек вообще смог войти

Пока этот блок не сделан, зарегистрироваться можешь только ты сам.
Всё остальное — украшения.

### 1.1. Site URL в Supabase — 2 минуты, никаких DNS (ТЫ)
- [ ] Supabase → **Authentication** → **URL Configuration**
- [ ] **Site URL**: `https://твой-домен`
- [ ] **Redirect URLs** — добавить обе строки:
      `https://твой-домен/**` и `https://tynysh.vercel.app/**`
- [ ] Save

Проверка: открыть сайт в режиме инкогнито — должен открыться экран входа.

### 1.2. Resend — отправитель писем (ТЫ)
- [ ] resend.com → регистрация
- [ ] **Domains** → **Add domain** → вписать домен
- [ ] Resend покажет 2–3 записи (Type / Name / Value) — **не закрывай эту страницу**
- [ ] Перенести эти записи туда, где живёт DNS домена:
      - если nameservers Vercel → vercel.com → вкладка **Domains** наверху страницы
        (не внутри проекта!) → домен → **DNS Records** → **Add**
      - если nameservers регистратора → в панели регистратора, раздел DNS
- [ ] Дождаться статуса **Verified** (10–30 минут)
- [ ] **API Keys** → **Create API Key** → скопировать `re_...` (показывается один раз)

### 1.3. SMTP в Supabase (ТЫ)
- [ ] Supabase → **Project Settings** → **Authentication** → **SMTP Settings**
- [ ] Включить **Enable Custom SMTP**:
      Host `smtp.resend.com` · Port `465` · Username `resend` ·
      Password — ключ `re_...` · Sender email `hello@твой-домен` · Sender name `Tynysh`
- [ ] Save

### 1.4. Лимит писем (ТЫ)
- [ ] Supabase → **Authentication** → **Rate Limits** → письма в час → **100** → Save

Это и есть причина «подожди пару минут»: у встроенной почты лимит ~2 письма
в час **на весь сайт**, не на человека.

### 1.5. Код в письме (ТЫ)
- [ ] Supabase → **Authentication** → **Emails** → **Templates** → **Magic Link**
      (и то же для **Confirm signup**), добавить:
      `<p>Твой код для входа: <b>{{ .Token }}</b></p>`
- [ ] Save

После этого ссылка вообще перестаёт быть нужна — хватит шести цифр.
Это чинит все три причины, по которым ссылка ломалась.

### 1.6. Проверка блока (ТЫ)
- [ ] Попросить постороннего человека (НЕ свой адрес) зарегистрироваться с телефона
- [ ] Письмо пришло за минуту, код подошёл, чат открылся

**Пока эта галочка не стоит — запускаться нельзя.**

## Чего я сделать не могу

Supabase, Vercel и Resend — сайты, куда вход только под твоим логином.
Из этой среды они вообще закрыты по сети, и ключей от твоих аккаунтов у меня нет.
Поэтому все пункты «ТЫ» — правда твои, я могу только вести по шагам.

Что я могу и делаю: весь код, все SQL-файлы, тексты, документы, расчёты,
а ещё — проверить домен снаружи (куда он смотрит, чьи nameservers, дошли ли
записи Resend). Для этого нужно одно: **напиши название домена.**
