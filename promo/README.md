# Картинки, которые можно показывать людям

| Файл | Размер | Куда |
|---|---|---|
| `post.png` | 1080×1080 | лента Instagram, статус WhatsApp, пост в Telegram |
| `story.png` | 1080×1920 | сторис |
| `poster.png` | A4, 1588×2246 | печать: доска объявлений в школе, раздать на руки |

Текст лежит рядом в `.html`. Поправил текст — перерисуй:

```
node scripts/make-promo.mjs
```

## Что на них написано и почему именно это

Каждое утверждение — правда, проверенная по коду:

- **10 сообщений бесплатно** — столько лежит в `app_settings.dos_free_total`.
- **Переписку видишь только ты** — это правило стоит в самой базе (RLS),
  не на словах.
- **Без рекламы** — её нет и не планируется.
- **Ставится на телефон** — через браузер, страница `/install`.
- **Дос — помощник, а не врач** — стоит на каждой картинке, не мелким шрифтом.
- **150 и 112** — на каждой картинке. Человек, которому плохо прямо сейчас,
  должен увидеть номер, даже если дальше рекламы не читал.

Разговор на картинках — про «не могу заставить себя». Это сознательный выбор:
так человеку не стыдно переслать картинку другу. «Там помогают, когда плохо»
перешлют единицы, «там помогают начать делать» — многие.

Чего на них нет: обещаний чатов и групп (они выключены) и слова «психолог»
в любом виде.
